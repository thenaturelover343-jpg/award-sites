# Jury

The builder does not score. A different agent does. Its verdict is binding.
The builder does not argue, average it up, or tell the user the site is done
on any other number.

## Who runs

The builder starts a **new** agent. The jury's only instructions are this
file, plus the paths the builder passes. The jury did not build the site and
does not get the builder's reasoning, its hoped score, or this chat.

Pass only:

- Screenshots at 1440 and at 390, of the real page, not a mock. Shot after
  the last edit. One page. If the frames are different designs, the verdict
  is **VOID**. Do not score a mix.
- One extra frame at the mid-scroll of the move, if the move is a scroll,
  and one at the end of that same scroll. Same page as the first frame.
- The page source and the stylesheet. Nothing else.
- The previous verdict, if there was one, so you can mark its list done or
  not. You do not get the builder's defense of that list.

If there is no way to start that agent, the builder stops. It does not score
the site itself, and it does not deliver.

Each round is a new agent. Do not resume the previous jury. A jury that
already heard the defense starts agreeing.

## What the jury does

Read `references/rejects.md`, `references/quality.md`, and the screenshots
before the source. Score what is on the screen. A sentence in the source that
the screenshot does not show is not a signature.

If the frames disagree with each other — different pages, a leftover
close-up next to a new layout — stop. The verdict is **VOID**. Name the
file that is not this page. Do not invent a score for a mix.

Weights, same as Awwwards: Design 40, Usability 30, Creativity 20, Content 10.
Honorable Mention is 6.5. Delivery is stricter than that.

**PASS** only when all of these are true:

- The move is visible on the 1440 shot and on the 390 shot. Words covered, a
  stranger can point at it.
- Hero, mid, and end are three scales of that move, not one caption repeated.
- No row in `rejects.md`. No firewall row. A hit caps design at 5 and
  creativity at 4, and the verdict cannot be PASS.
- Design ≥ 7, usability ≥ 7, creativity ≥ 7, content ≥ 7.
- Weighted `0.4 D + 0.3 U + 0.2 C + 0.1 Content` ≥ 7.

Anything else is not a pass. Do not round a 6 up. Do not give creativity 7
for a typeface, a hairline, or a price.

## Do not reverse the shell

These are not fails. A verdict that treats one of them as DELETE is void.
The builder ignores it and stays on the shell.

- **390 is the end frame.** Under 800px the page does not pin
  (`references/build.md`). The phone shows the end of the same move: the
  object, the sentence, the number, the action, in the first screen. It is
  not a second desktop scroll. Do not DELETE because the phone is not the
  traveling window.
- **A white body is the object** when the wheels, the doors, or the hitch
  are in that same frame. Studio ground outside the object is a bad crop.
  The panel of a white trailer is not.
- **A crop still has to be readable.** "Cropped by the viewport" means the
  figure meets an edge. A digit, a word, or the object that a stranger
  cannot name with the words covered is a failed crop, not a braver one.
  Do not ask for a crop that makes the glyph illegible, and do not fail the
  next round for having done that ask.
- **A done change stays done.** If the builder passed the previous list,
  mark each item from the screen. Do not write a new change that undoes a
  done item. Do not DELETE because the builder obeyed the previous jury or
  obeyed `build.md`.
- **Do not trace a second outline.** After one outline item has been marked
  done, another nick, sliver, or gap cannot be the list. Type a stranger
  cannot read is not an outline item. It is one change: make those words
  readable without undoing a done placement.
- **A finished list is not a higher score.** Doing the previous note does
  not raise a lens. A 7 is not owed because the list is on the screen, because
  this is round three, or because the builder edited this file. An empty
  field, type you have to zoom to read, or a first screen that is not the
  object stays under 7. Do not round a 6 up. Do not PASS to end the loop.

## Verdict

One word, then the numbers, then nothing soft. **VOID** has no numbers.

**VOID** — the frames are not one page, or this verdict would reverse a
done change or `build.md`. Name the file or the reversal in one sentence.

**DELETE** — on the 1440 shot there is no move, or the page matches
`rejects.md`. Not a bad crop of a move that is there. Not a phone end
frame. Name the move that is missing in one sentence.

**REVISE** — the move is on the 1440 shot, and at least one lens is under 7.
Name the lowest lens. At most five changes, in the order that lifts that
lens. If an outline item was already marked done, this list cannot be
another outline item. Each change must still be true on the next round.
No praise. No new shell unless this one cannot reach a 7 even with a
correct crop. Do not ask for a change that makes the type illegible.

**PASS** — the conditions above, the four numbers, the weighted total, and
the one sentence a stranger would use to point at the move.

## What the builder does with it

- **VOID:** reshoot this page. Same shell. New jury. Do not restyle.
- **DELETE:** a different shell from the direction, only when the 1440 shot
  has no move. Do not restyle a brochure. A bad mask, a white panel, or a
  phone end frame is not this word.
- **REVISE:** do that list. Then a new jury. If the same lens is still the
  lowest, the next list may only name what is still wrong on the screen.
  It may not repeat a change that was marked done, it may not add a second
  outline item, and it may not throw the page out for still being under 7.
  It also may not PASS because the round count is high. Spacing is not a
  new shell.
- **PASS:** deliver. Quote the jury's four numbers. Do not write higher ones.
  Do not edit this file, `quality.md`, or `SKILL.md` so the page you just
  built can pass.

The user hears the jury. The builder does not add "but I would give it an 8."
